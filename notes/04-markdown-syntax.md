# Markdown 语法速查

> [!NOTE]
> 这个记事本用的是自研轻量渲染器（零外部依赖），支持下面这些语法。

## 基础

**粗体**、*斜体*、~~删除线~~、==高亮==、`行内代码`

[链接](https://commonmark.org) 和自动链接：https://golang.org

## 列表

- 无序列表
- 支持嵌套
  - 第二层
  - 第二层
- 回到第一层

1. 有序列表
2. 第二项
3. 第三项

## 任务列表（可勾选）

- [x] 已完成的事项
- [ ] 未完成的事项
- [ ] 点击方框可以直接勾选

> [!TIP]
> 任务勾选会写回笔记内容，导出时也带着状态。

## 表格（支持对齐）

| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| a | b | c |
| 长一点的文字 | 中 | 1234 |

## 代码块

```go
func main() {
    fmt.Println("hello")
}
```

## 标题锚点

每个标题会生成 `id`，可以直接用 `#md-三个角色` 这样的锚点跳转。

---

## 不支持的语法

- 数学公式（KaTeX / MathJax）
- Mermaid 图表
- 脚注 `[^1]`
- HTML 内嵌

这些都需要引入外部库，会破坏「零依赖、可离线」的原则。
